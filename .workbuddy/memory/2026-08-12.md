# 2026-08-12 工作日志

## WebPhAPI 协议重写
- 完全删除旧请求格式 (query/text/target URL 参数)
- 新格式: URL `?` 后全部内容作为 JSON5 解析 (复用 SConfig 的 jsonc 解析能力)
- 输入 schema: `{target?: String|null, query?: (String|JSONObject)[]}`
- `query` 数组中:
  - **String 元素**: 使用外层 `target` 解析 Placeholder，智能 `%` 包裹 (两端都有 `%` 保持原样，否则自动包裹；一半包裹视为未包裹)
  - **JSONObject 元素**: 从 `target`/`key` 属性取值，`inner.target=null` 时不继承外层 target
- 输出: `{timestamp: Long, result: String[]}`，按 query 数组顺序返回每个查询的结果
- 删除 `isUsableHolder` / 白名单过滤 / `newPlaceholderJsonResponse` 等旧逻辑
- Git commit: `87fa755` (Neonai)

## WebPhAPI 安全过滤恢复
- 用户指出无鉴权 API 必须有占位符过滤，防止数据泄露
- `resolvePlaceholder()` 解析前提取 bare name（去 %），经 `isAllowed()` 校验
- 未通过过滤返回 `[forbidden]`，不返回真实解析值
- `isAllowed()` 读取 `APIHolders.white-mode` + `APIHolders.ph_list`
- white-mode=true：白名单模式，只允许列表中存在的；false：黑名单模式，只拒绝列表中存在的
- 支持两种规则写法：普通字符串（忽略大小写全匹配）+ `regex:` 正则
- 空名单：白名单全部拒绝 / 黑名单全部允许
- 同时修复了 `APIHoldersMain.CONF` 中错误的 config 路径（history bug）
- Git commit: `d6555f5` (Neonai)
