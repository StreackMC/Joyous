# 2026-11-12 工作记录

## 交互层：输入提示的发送职责上移到 transport

用户要求：消费端新建 input 时只提供「要输入什么」与「旧值是什么」，不再自己发聊天消息，
由处理器统一格式化再发送。

- 新增 `interact/IPageObserver`：`onPageShown(IPageContext)` / `onPageHidden(IPageContext)`，
  主线程回调、旁路通知（失败只记日志，不影响转移）。
- `PlayerPages` 新增 `Events` 出口（`shown`/`hidden`），在 `promote()` 的 attach/resume 之后
  （带「页面可能在自己的 onAttach 里就关掉自己」的状态守卫）、`retireVisible()` 的挂起分支、
  `detach()` 之后各调一次。
- `PageArbiter` 维护 observer 列表（`addObserver/removeObserver`，CopyOnWriteArrayList），
  `install` 时把 `ChatInput` 同时注册为 Listener 与观察者；所有玩家的状态机共用一份 events。
- `ChatInput` 实现 `IPageObserver`：**页面显示时发提示并起超时**，隐藏时撤计时器；
  `format(ChatPrompt)` 改为私有（唯一出口）；取消/超时提示也都在这里发。
- `AbstractChatPage` 瘦成只声明 `keepable=false`，不再有计时器与 `sendMessage`。
- `Canvas` 增加带光效的 `button(..., glow)` 重载（「当前选中项」高亮）。

## I2c-2a：Ward 四个纯按钮子界面迁入页面层

- 新增 `WardSubPage`（公共基类：`profile()` / `save()` / `backToEditor()` / `open()` / `openChat()` / `tell()`）。
- 新增 `WardContainerPickerPage`、`WardRowsPage`、`WardMaxDrawPage`、`WardDistributionPage`。
- `WardEditorGui` 删掉 4 个 `openXxx` 与 3 个 `handleXxxClick`（-289 行），
  渲染辅助（`drawButton`/`distributionButton`/`curveButton`/`applyCurve`/`applyDraw`/`formatCurve`/
  `maxDrawRows`/`maxDrawSlot`）改包内可见并由页面调用。
- 子界面之间一律 `REPLACE`（换一页，不是叠加）；文本输入仍用 `INSTANT`（挂起当前页，结束自动恢复）。
- `WardGui.Kind` 只剩 `ITEM_EDITOR`；`WardListener` 的点击/关闭分支与 `SUBMENUS` 收敛到只处理它。
- 顺带修掉旧账：`MAX_DRAW_SIZE`（static final，类加载时算死）删除，容量改由页面 `rows()` 现算，
  档位数变化不会再越界。
- 新增语言键 `jwardchest.input.field.min_draw` / `max_draw`（`%s` = 珍惜度名）。
