# 2026-11-08

## JwardChest：新增「禁止放入外来物品」开关

- 配置 `JwardChest.session.allow-foreign-place`（默认 true）。
  - `false` 时只接受带 `joyous:jc_rarity` 标记的物品（= 本模块产出），其余在事务里被拒。
  - 与 `session.allow-place`（总开关）串联：总开关关掉时容器只出不进，本项无意义。
- `WardTag.hasTag()` 新增：**只判断标记键在不在**，不校验 id 是否还在 rarities 声明里——
  否则管理员删掉某一档后，先前抽出去的物品会突然变成"外来物"。搜索时长的兜底仍由
  `rarityOf()` → `fallback()` 负责，两件事互不影响。
- `WardSession.OpResult` 新增 `FOREIGN_ITEM`；`WardSearchController.acceptsPlacement()` 在
  `transact()` 内（校验阶段）判定，仍是「锁内校验+修改、锁外落库派发」那一套。
- 新文案 `jwardchest.container.foreign_denied`。i18n 136 键齐全，package 通过，jar 已部署到
  `mcserver/plugins/Joyous-0.3.0.jar`。
- 注意：这项只限制"放进来"，不会动已经在箱子里的外来物品（不做事后清理）。
