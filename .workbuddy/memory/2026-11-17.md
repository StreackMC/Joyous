# 2026-11-17

## Common 模块：背包 2x2 合成限制

- 需求：玩家**显式缺失** `joyous.common.invcraft` 时无法使用背包 2x2 合成方格。
- 判定语义 = `isPermissionSet(node) && !hasPermission(node)`：权限从未设置 → 放行（opt-out，不影响任何现有玩家）；仅被显式 `-joyous.common.invcraft` → 禁用。权限用 `PermDef.all` 注册（default TRUE，只是让节点可见）。
- 新建 `Common/InvCraftListener.java`：拦 `InventoryType.CRAFTING`（**只**玩家背包合成网格，不碰工作台 `WORKBENCH`）的 rawSlot 0~4。四处拦截：
  · `InventoryClickEvent`（放入/取出/Shift 点击，HIGH + ignoreCancelled）
  · `InventoryDragEvent`（拖入材料，rawSlots 命中 0~4）
  · `PrepareItemCraftEvent` → `setResult(null)`（结果格不出产物）
  · `CraftItemEvent` → cancel（真正拿走产物的兜底）
- `CommonMain.onEnable()` 注册权限 + `Bukkit.getPluginManager().registerEvents(new InvCraftListener(), Joyous.plugin)`；`pluginManager`/`plugin` 在 entry.onEnable(:66,:70) 已就绪，模块 onEnable 在其后调用，安全。
- 构建 `mvn -o clean package` 通过。
